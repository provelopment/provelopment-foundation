This is a live reference for the open-source Provelopment Foundation template. It is built from the public Foundation code, which you can download, adapt and deploy from your own repository.

# What this site demonstrates

This is a working Foundation website, not a mock-up. It demonstrates:

- a Home page created with declarative JSON
- this About page created with Markdown
- English and German versions of the same website
- Sidebar and Menu-bar layouts
- a second demonstration website for Germany in the same Foundation Installation
- location-specific information through the Germany website's Berlin and Frankfurt examples

The aim is to show the main Foundation capabilities working together without making the example more complicated than it needs to be.

# A website you control

Foundation is designed so that you remain in control of your website.

Your pages, images and other content live as files in your repository. Configuration files define how the website behaves, and the site is built from that source rather than being locked inside a proprietary website builder.

You can maintain it yourself, ask another provider to maintain it, or use Provelopment services. The choice is yours.

# Two ways to create pages

Foundation supports two page-authoring formats.

**Markdown** is the simple choice for ordinary content pages. It stays easy to read and edit while supporting headings, lists, links and other common formatting.

**Declarative JSON** is useful when a page needs more structure. It lets you arrange sections such as heroes, columns, cards, tables and questions.

This page uses Markdown. The Home page uses JSON.

Both are ordinary Foundation pages and become part of the website from the files you author.

# Websites, languages and locations

A Foundation Installation can be simple or more advanced.

This demonstration contains two separate websites: the Global website you are reading and a Germany website reached through the footer. Each has its own content and address while sharing the same Foundation Installation.

Both websites are available in English and German. The Germany website also demonstrates **Berlin** and **Frankfurt** as locations within that website.

The controls shown to visitors depend on the configuration. This website needs **Language** and **Layout**; the Germany website also has **Location**.

# This configuration is only an example

The languages, websites and locations used here are demonstration choices. They are not statements about Provelopment's own markets, offices or operating structure.

When you use Foundation, replace them with the structure and content that suit your organisation.

# Open source as the foundation

**Foundation is free and open source: download it, deploy it, modify it and make it your own.**

Provelopment services are optional. Provelopment can build, extend or maintain a Foundation website, but you do not need those services to keep using it.

Your repository remains the source of your website, and you remain free to operate it yourself, move it elsewhere or have another provider maintain it.
